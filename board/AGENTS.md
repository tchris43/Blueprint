# board

The team-wide working rules in the root `AGENTS.md` apply here: explain the plan before writing
code, work in small steps, don't edit tests or `shared/` without telling the team, and be able to
explain your piece in 2 minutes.

- **Tests for this folder:** `pnpm test:board`. Run them after every step.
- **Start here:** the ticket you're on in `tickets/`, and its task file in `tasks/board/`. Mockups are in `docs/mockup/`.
- **Tests here define done:** `board/web/src/__tests__/`. If one looks wrong, explain why and stop; don't change it.
